# MHotel - Hotel Management System


## About the Project
MHotel is a hotel management and reservation system developed using ASP.NET MVC 5 and Entity Framework 6.

The application allows users to browse available hotels, search for hotels, and manage reservation.


## Technologies
 
- **C#
- **ASP.NET MVC 5
- **Entity Framework 6
- **SQL Server
- **HTML, CSS
- **JavaScript


## Main Features
- **View Hotels
- **Search Hotels
- **Reservation Management


## Planned Features
- **Login page
- **User authentication
- **User access control


## Database Structure
The database includes the folowing entities :
-Hotel
-Reservation
-Service
-HotelService


## Project Architecture
The Solutions consists of two main projects :
### Core
 Contains the main application layers :
 - **Application:** Application logic
 - **Domain:** Entities and AppDbContext
 - **Model:** Application models
 - **ViewModel:** View models used to transfer data between application layers and views

 
### Web.UI
 Contains :
 - Controllers
 - Views
